\section{Conclusion}
This project successfully developed an image-based garbage classification system that identifies glass, plastic, paper and metal waste. By combining a pre-trained \textbf{MobileNetV2} with data augmentation, dropout, early stopping and fine-tuning, a high-accuracy model was obtained from a small dataset with modest computing resources. The model achieved a test accuracy of \textbf{85--87\%}, and it was deployed as a simple Gradio web application. The comparison with published work shows that the lightweight MobileNetV2 approach gives a good balance of accuracy, speed and size. With larger datasets and object detection, the system can be extended into a practical tool that supports automated waste segregation and a cleaner environment.
