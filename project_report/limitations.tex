\section{Limitations}
\begin{itemize}
  \item TrashNet images are single objects on a plain white background; accuracy may fall for cluttered real-world scenes.
  \item The dataset is small (about 2,000 images in four classes), and the classes are slightly imbalanced.
  \item The system classifies only one item per image; multiple items would need an object-detection model such as YOLO.
  \item Organic waste, cardboard, e-waste and hazardous waste are not covered.
  \item Soiled, crushed or transparent items may be misclassified.
\end{itemize}
