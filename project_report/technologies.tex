\subsection{Key Concepts}
\begin{itemize}
  \item \textbf{Convolutional Neural Network (CNN):} a neural network that learns visual features from images.
  \item \textbf{Transfer learning:} reusing a model trained on a large dataset (ImageNet) for a new, smaller task.
  \item \textbf{Fine-tuning:} unfreezing the last layers of the base model and training them with a very low learning rate.
  \item \textbf{Data augmentation:} creating modified copies of training images to reduce over-fitting.
  \item \textbf{Softmax:} the output function that converts scores into class probabilities that sum to one.
  \item \textbf{Dropout and early stopping:} regularisation techniques that prevent over-fitting.
\end{itemize}
