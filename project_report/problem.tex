\section{Problem Statement and Objectives}
\subsection{Problem Statement}
To design and implement an automated system that takes an image of a waste item as input and classifies it into one of four categories --- \textbf{glass, plastic, paper or metal} --- with high accuracy, and to make the system usable through a simple web interface.

\subsection{Objectives}
\begin{itemize}
  \item To study and prepare the TrashNet dataset for a four-class garbage classification task.
  \item To apply transfer learning using a pre-trained MobileNetV2 model for accurate classification with limited data.
  \item To reduce over-fitting using data augmentation, dropout, early stopping and checkpointing.
  \item To improve accuracy further by fine-tuning the top layers of the base network.
  \item To evaluate the model on unseen test data and compare it with other published models.
  \item To deploy the trained model as an easy-to-use web application using Gradio.
\end{itemize}
