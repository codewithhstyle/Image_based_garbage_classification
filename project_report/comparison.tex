\subsection{Analysis}
The older and heavier networks in Table~\ref{tab:cmp} (VGG-19, ResNet-50, GoogLeNet) need many more parameters, memory and computation than MobileNetV2, which has only about 3.4 million parameters. ResNet-50 has roughly 25 million and VGG-19 roughly 140 million parameters. MobileNetV2 therefore trains faster and predicts faster, which suits a laptop or low-cost device. A separate study also found MobileNetV2 more accurate than VGG16 (95.6\% vs 89.13\%) while being much lighter~\cite{mobvgg}. This project also classifies four clearly different material classes, which is an easier task than the six-class version that includes the ambiguous \textit{trash} class, so results should be compared with that difference in mind.
