\section{Future Scope}
\begin{itemize}
  \item Add more classes (cardboard, organic, e-waste, batteries) and train on larger datasets such as TACO.
  \item Use object detection (YOLO) to find and classify several items in one image.
  \item Convert the model to TensorFlow Lite for mobile apps and Raspberry Pi based smart bins.
  \item Connect the classifier to a camera and a robotic arm or servo-based sorting mechanism.
  \item Collect real-world images to improve robustness, and try newer backbones such as EfficientNet.
\end{itemize}
